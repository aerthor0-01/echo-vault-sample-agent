# echo-vault-sample-agent (SAMPLE DATA)

A fictional agent, **Atlas**, used to demonstrate [Echo Vault by EchoState](https://vault.echostate.cloud).

## Demo script (change → capture → review)
1. Track this repo in Echo Vault; it auto-detects AGENTS.md, SOUL.md, MEMORY.md, CLAUDE.md, `.cursor/rules`, `prompts/` and `tools/manifest.json`.
2. Edit a file here (e.g. enable `send_email` in `tools/manifest.json`, or add a rule to AGENTS.md).
3. Click **Sync now** in Echo Vault → a new version with a receipt, file diff and rule warnings (e.g. new write tool).
4. Approve, label production, then `pull` it back with the connector.

Nothing here contains real credentials or customer data.
